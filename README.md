# WeekPay - AI-Powered Personal Budgeting Dashboard

A modern web application for tracking weekly income and managing personal finances using the 50/30/20 budgeting rule.

## Features

- Weekly income tracking with automatic budget breakdown
- 50/30/20 rule implementation (Needs/Wants/Savings)
- Currency conversion between USD and INR
- Interactive data visualization with charts
- Budget history tracking
- AI-powered insights and suggestions

## Tech Stack

- Frontend: Next.js, TypeScript, Tailwind CSS
- Data Visualization: Chart.js
- State Management: React Hooks
- API: Next.js API Routes

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Raghavendra-Yadav/weekpayv2.git
   cd weekpay
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
